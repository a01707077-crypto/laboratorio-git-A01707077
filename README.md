## Reflexión 

•	¿Qué parte de la práctica te resultó más confusa y cómo la resolviste?
Entender el proceso de add, commit, pull, push, status, ya que pensé que solo era poner las indicaciones, y que sólo se iba a ir corriendo, pero es entender la lógica y como cada paso es fundamental seguir para una buena ejecución. Para resolverlo tuve que entender primero como se componía un file y como se iba agregando cada file a un folder, ya que sólo ponía puros push y no sabía como se iban guardando.Entendiendo la composición, pude entender el proceso.  


•	¿Cómo crees que tu equipo usará el repositorio durante las etapas de UX y UI?

Durante la fase de UX mi equipo usará el GitHub para documentar crear y gestionar temas con requerimientos de usuario, y sincronizar la documentación del proyecto dentro del repositorio en VS Code. 
En la etapa de UI, revisaremos los componentes, hojas de estilo y activos visuales directamente mediante las herramientas de control de versiones integradas en VS Code. Finalmente, el repositorio servirá como una única fuente de verdad donde podremos revisar y aprobar el código visual mediante pull requests antes de integrarlo a la entrega final.
